# Hellom Page fonts

Self-hosted copies of Google Fonts families, Latin subset, used by Hellom Page shop pages and the
editor's font picker. All are licensed under the SIL Open Font License 1.1; each font's license
text (with its copyright notice) is in the matching `*.OFL.txt` file.

Generated by `frontend/scripts/fetch-landing-fonts.mjs`.

- `jakarta` — Plus Jakarta Sans (`jakarta.OFL.txt`)
- `inter` — Inter (`inter.OFL.txt`)
- `poppins` — Poppins (`poppins.OFL.txt`)
- `montserrat` — Montserrat (`montserrat.OFL.txt`)
- `dmsans` — DM Sans (`dmsans.OFL.txt`)
- `spacegrotesk` — Space Grotesk (`spacegrotesk.OFL.txt`)
- `playfair` — Playfair Display (`playfair.OFL.txt`)
- `lora` — Lora (`lora.OFL.txt`)
- `dmserif` — DM Serif Display (`dmserif.OFL.txt`)
- `bebas` — Bebas Neue (`bebas.OFL.txt`)
- `archivo` — Archivo Black (`archivo.OFL.txt`)
- `caveat` — Caveat (`caveat.OFL.txt`)
